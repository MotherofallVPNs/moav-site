# Video tutorials

Community-made walkthroughs of installing and running MoaV.

!!! info "Only in Farsi so far"
    The one tutorial we have is in Farsi. Switch the language in the top bar (**فارسی**) and this page shows it — a full server walkthrough by [@iaghapour](https://x.com/iaghapour).

    There is no English walkthrough yet. If you make one, open an issue or a PR adding it here and we will link it: a screen recording of a real install is worth more than any amount of prose, and it tends to surface bugs the maintainers never hit. The Farsi video did exactly that — several fixes in [2.1.0](https://github.com/MotherofallVPNs/MoaV/blob/main/CHANGELOG.md) came from watching it.

If you would rather read than watch, [Quick Start](quick-start.md) is the same path in about ten minutes.

## What a good tutorial covers

Useful if you are thinking of recording one — roughly the order a new operator needs:

1. Getting a VPS and pointing a domain at it ([VPS Deployment](DEPLOY.md), [DNS Configuration](DNS.md))
2. The one-command install, and what `moav bootstrap` asks
3. Creating a user and sending them their bundle (`moav user add NAME --package`)
4. Connecting from a phone — importing a config, and which app for which protocol ([Client Apps](CLIENTS.md))
5. What to do when one protocol is blocked: switching, and `moav doctor`

Credit stays with the author, and we link rather than re-host.
