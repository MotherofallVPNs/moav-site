# شروع سریع

MoaV را نصب کنید، بعد به کسی لینکی بدهید که او را وصل می‌کند. کل مسیر همین است و حدود ده دقیقه طول می‌کشد.

MoaV [بیش از ۱۶ ترابرد و مسیر جایگزین عبور از فیلترینگ](protocols.md) را راه می‌اندازد، به‌همراه یکپارچه‌سازی‌های اختیاری اهدای پهنای‌باند با Psiphon، Tor و MahsaNet، و برای هر کاربر یک **بسته** آمادهٔ اشتراک‌گذاری می‌سازد: فایل‌های تنظیمات، کدهای QR و راهنمای ساده به انگلیسی و فارسی. کسی که بسته را می‌گیرد لازم نیست چیزی از این‌ها بفهمد. کنجکاوید چرا این پروژه وجود دارد؟ [مأموریت](philosophy.md) را بخوانید.

## آنچه لازم دارید

- **یک سرور** — Debian 12 یا Ubuntu 22.04 و 24.04، یا یک **Raspberry Pi 4 یا بالاتر** (ARM64). کمینه ۱ هستهٔ پردازنده و ۱ گیگابایت رم؛ اگر مانیتورینگ می‌خواهید ۲ گیگابایت.
- **یک دامنه** — اختیاری، اما ارزشش را دارد. چند ترابرد دیگر را در دسترس می‌گذارد، به‌ویژه پروکسی‌های مبتنی بر TLS و همهٔ تونل‌های DNS، که می‌توانند در شرایطی که ترافیک معمولی بسته است اما DNS بازگشتی هنوز پاسخ می‌دهد کار کنند. ببینید [آیا به دامنه نیاز دارم؟](DNS.md#do-i-need-a-domain).

!!! tip "DNS را *پیش از* نصب تنظیم کنید"
    صدور گواهی نیاز دارد که دامنه از قبل به سرور اشاره کند، پس اگر رکوردها را اول اضافه کنید نصب روان پیش می‌رود. رکوردهای دقیق در [تنظیمات DNS](DNS.md#with-a-domain-the-records) آمده‌اند — و بعد از نصب، `moav doctor dns` آن‌ها را در قالب فایلی می‌نویسد که می‌توانید مستقیم به Cloudflare وارد کنید.

    هنوز سروری ندارید؟ [راه‌اندازی روی VPS](DEPLOY.md) مرحله‌به‌مرحله برای هر ارائه‌دهنده، از حدود ۵ دلار در ماه. روی سرور خانگی یا Pi، اول CGNAT را بررسی کنید و [پورت‌های پروتکل‌ها](DNS.md#ports-to-forward) را فوروارد کنید.

## ۱. نصب

با SSH وارد شوید و این را اجرا کنید:

```bash
curl -fsSL moav.sh/install.sh | bash
```

این دستور Docker را نصب می‌کند، MoaV را کلون می‌کند و سه چیز می‌پرسد: **دامنه** (برای حالت بی‌دامنه خالی بگذارید)، یک **ایمیل** برای Let's Encrypt، و یک **رمز مدیریت** — که رمز Grafana هم هست، پس رمز واقعی انتخاب کنید.

وقتی تمام شد، نشانی پنل‌ها و رکوردهای DNS را که باید اضافه کنید چاپ می‌کند.

## ۲. نخستین کاربر را بسازید

دو راه دارد. هر کدام را ترجیح می‌دهید استفاده کنید — نتیجه یکی است.

=== "پنل وب"
    نشانی **`https://your-server:9443`** را باز کنید و وارد شوید — **هر نام کاربری**، با همان رمز مدیریتی که انتخاب کردید.

    ??? warning "مرورگر دربارهٔ گواهی هشدار می‌دهد"
        در حالت بی‌دامنه، پنل از گواهی خودامضا استفاده می‌کند، پس بار اول هشدار حریم خصوصی می‌بینید. این طبیعی است — از آن بگذرید. اگر دامنه تنظیم شده باشد، از گواهی Let's Encrypt شما استفاده می‌کند و هشداری نیست.

    روی **+ New** بزنید، یک نام بدهید، و کاربر در جدول ظاهر می‌شود با یک نشان برای هر پروتکلی که گرفته است — Reality، Trojan، Hy2، CDN، WG، AWG، XHTTP و مانند این‌ها. برای دانلود بسته‌اش **.zip** را بزنید.

    پنل ساده‌ترین جا برای کار روزمره است: همهٔ کاربران را با تاریخ ساخت و پروتکل‌هایشان فهرست می‌کند، بسته‌ها را در همان لحظه دانلود می‌کند، و آمار زندهٔ سرور را نشان می‌دهد.

=== "خط فرمان"
    ```bash
    moav user add alice              # یک کاربر
    moav user add alice --package    # ...و ساختن فایل zip
    moav user add --batch 10         # ده کاربر یک‌جا
    moav user list                   # چه کسانی هستند
    ```

    بسته‌ها در `outputs/bundles/alice/` ساخته می‌شوند.

هر دو راه به یک بستهٔ یکسان می‌رسند:

- **`README.html`** — همان فایلی که باید بفرستید. راهنمای مرحله‌به‌مرحله به انگلیسی و فارسی، همراه کدهای QR. کاربر بازش می‌کند، سیستم‌عاملش را انتخاب می‌کند، QR را اسکن می‌کند و وصل است.
- فایل‌های تنظیمات و لینک‌های اشتراک برای هر پروتکل فعال و درست‌تنظیم‌شدهٔ سمت کاربر، به‌همراه یک **اشتراک** (subscription) که با یک بار چسباندن در MahsaNG، v2rayNG و Hiddify کار می‌کند.

بسته را از راهی خصوصی بفرستید — Signal، ایمیل رمزنگاری‌شده، یا حضوری. برای این‌که به هر کاربر بر اساس سیستم‌عاملش چه بگویید، [اپلیکیشن‌های کاربر](CLIENTS.md) را ببینید.

## ۳. این چهار فرمان را بشناسید

```bash
moav status    # چه چیزی در حال اجراست، کدام پروفایل‌ها بالا هستند، سلامت در یک نگاه
moav doctor    # عیب‌یابی: DNS، پورت‌ها، گواهی‌ها، منابع
moav logs      # دیدن لاگ یک سرویس وقتی درست کار نمی‌کند
moav test alice  # اثبات این‌که تنظیمات alice واقعاً ترافیک را رد می‌کنند
```

وقتی چیزی درست به نظر نمی‌رسد، اول از همه `moav doctor` را بزنید — چیزهایی را بررسی می‌کند که بیشتر از همه خراب می‌شوند و معمولاً مشکل را صریح نام می‌برد. `moav test` را پیش از آن‌که به کسی بگویید بسته‌اش کار می‌کند اجرا کنید، چون واقعاً از هر پروتکل وصل می‌شود و IP خروجی را گزارش می‌دهد.

اجرای خالی **`moav`** یک منوی تعاملی روی همهٔ این‌ها باز می‌کند، پس چیزی برای حفظ کردن نیست. هر گزینه به یک فرمان در [مرجع خط فرمان](CLI.md) نگاشت می‌شود.

## ۴. کارکردنش را ببینید (اختیاری)

اگر مانیتورینگ را فعال کرده باشید، **Grafana** روی **`https://your-server:9444`** است — کاربر `admin`، با همان رمز.

ده داشبورد از پیش آماده می‌آید، پس چیزی برای ساختن نیست:

| داشبورد | چه می‌گوید |
|---|---|
| **sing-box** | اتصال‌ها و پهنای‌باند هر کاربر برای Reality، Trojan، Hysteria2، Shadowsocks |
| **WireGuard** · **AmneziaWG** | دست‌دادن‌های هر peer، حجم انتقال هر peer |
| **DNS tunnels** | ترافیک روی dnstt، Slipstream، MasterDNS، XDNS |
| **Xray** · **telemt** | فعالیت XHTTP/XDNS و Telegram MTProxy |
| **Conduit** · **Snowflake** | پهنای‌باندی که به کاربران Psiphon و Tor اهدا می‌کنید |
| **System** · **Containers** | پردازنده، حافظه، دیسک و منابع هر کانتینر |

مانیتورینگ را اجرا نمی‌کنید؟ `moav start monitoring` آن را روشن می‌کند — حدود ۲ گیگابایت رم می‌خواهد. جزئیات در [مانیتورینگ](MONITORING.md).
